# Darcy FNO 2D — 21 September 2026

## Scope

This tranche adds the first trainable two-dimensional neural operator to the
Darcy benchmark. The sparse conservative solver remains the truth oracle.

TorchFNO2D uses:

- input shape (batch, points_y, points_x, channels);
- normalized x/y coordinate channels appended before lifting;
- complex Fourier mixing on low positive and negative y frequencies;
- pointwise channel mixing in every block;
- right/bottom zero padding before spectral blocks for the non-periodic problem;
- a hard analytic envelope on the final pressure field so every rectangular
  boundary remains exactly zero.

The model uses float64 in this reference implementation to stay close to the
numerical oracle. It is not a production-optimized GPU kernel.

## Controlled benchmark

scripts/torch_darcy_fno2d_experiment.py trains on deterministic 9x9 Darcy
samples and reports four distinct measurements:

1. training objective reduction;
2. held-out 9x9 validation;
3. OOD coefficient contrast at a larger log-permeability standard deviation;
4. zero-shot execution on a 17x17 grid with the same learned parameters.

For each evaluation cohort the report includes MSE, global relative L2 error,
the conservative discrete Darcy residual, hard-boundary error, and inference
wall-clock timing.

## Scientific status

Running the same weights at a new resolution demonstrates architectural shape
compatibility. It does not by itself prove resolution invariance. Likewise,
an OOD result on one coefficient family is not evidence of general Darcy
generalization.

The next comparison gate is a matched-budget local 2D baseline and a nonlinear
DeepONet 2D under exactly the same train/validation/OOD/resolution cohorts.
A differentiable Darcy residual can then be added for a data-only versus
physics-informed comparison.
